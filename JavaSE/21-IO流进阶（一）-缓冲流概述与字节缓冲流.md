# IO流进阶（一）- 缓冲流概述与字节缓冲流

## 1. IO流体系回顾

```
IO流（按流向）
├── 输入流（读数据）
│   ├── 字节输入流  InputStream
│   └── 字符输入流  Reader
└── 输出流（写数据）
    ├── 字节输出流  OutputStream
    └── 字符输出流  Writer
```

```
IO流（按功能）
├── 节点流：直接连接数据源（如 FileInputStream / FileOutputStream）
└── 处理流 / 包装流：包装节点流，提供额外功能（如 BufferedInputStream / BufferedReader）
```

> **缓冲流就是典型的处理流/包装流**：包装节点流，在其基础上增加缓冲区功能。

## 2. 缓冲流概述

### 2.1 为什么需要缓冲流？

- **节点流**（FileInputStream/FileOutputStream）每次读写一个字节，频繁的系统调用（内核态 ↔ 用户态切换）导致性能低下
- **缓冲流**：在内部维护一个 **缓冲区（byte[] 或 char[]）**，一次读取一批数据到缓冲区，程序再从缓冲区中读写，减少了系统调用的次数

### 2.2 缓冲流的四大金刚

| 分类 | 字节流 | 字符流 |
|------|--------|--------|
| **输入** | BufferedInputStream | BufferedReader |
| **输出** | BufferedOutputStream | BufferedWriter |

### 2.3 构建方式：包装

缓冲流不能直接操作文件，必须包装一个节点流：

```java
// 字节缓冲输入流
FileInputStream fis = new FileInputStream("a.txt");
BufferedInputStream bis = new BufferedInputStream(fis);

// 字节缓冲输出流
FileOutputStream fos = new FileOutputStream("a.txt");
BufferedOutputStream bos = new BufferedOutputStream(fos);

// 字符缓冲输入流
FileReader fr = new FileReader("a.txt");
BufferedReader br = new BufferedReader(fr);

// 字符缓冲输出流
FileWriter fw = new FileWriter("a.txt");
BufferedWriter bw = new BufferedWriter(fw);
```

## 3. 字节缓冲流

### 3.1 BufferedInputStream

#### 构造方法

```java
BufferedInputStream(InputStream in)          // 默认缓冲区 8192 字节（8KB）
BufferedInputStream(InputStream in, int size) // 指定缓冲区大小
```

#### 原理

1. 创建时内部维护一个 **byte[] buf**（默认 8192 字节）
2. 读取时：
   - 先尝试从缓冲区读
   - 缓冲区空了 → 一次性从文件读取 8192 字节到缓冲区
   - 再从缓冲区返回一个字节
3. 实际 I/O 次数从 N 次降低到 N/8192 次

```java
// 核心源码（简化）
public class BufferedInputStream extends FilterInputStream {
    protected volatile byte buf[];  // 内部缓冲区
    protected int count;           // 缓冲区有效字节数
    protected int pos;             // 当前读取位置
    
    public synchronized int read() throws IOException {
        if (pos >= count) {
            // 缓冲区空了，从底层流读取一块数据填充
            fill();  // 调用 InputStream.read(byte[]) 读取 8192 字节
            if (pos >= count) return -1;
        }
        return buf[pos++] & 0xff;
    }
}
```

### 3.2 BufferedOutputStream

#### 构造方法

```java
BufferedOutputStream(OutputStream out)           // 默认 8192 字节缓冲区
BufferedOutputStream(OutputStream out, int size)  // 自定义缓冲区大小
```

#### 原理

1. 写入数据时先写到内部 **byte[] buf** 缓冲区
2. 缓冲区满了 → 自动调用 flushBuffer() 把数据真正写入文件
3. **注意**：close() 前一定要 flush() 或 close()，否则缓冲区残留数据会丢失

```java
// 核心源码（简化）
public class BufferedOutputStream extends FilterOutputStream {
    protected byte buf[];
    protected int count;
    
    public synchronized void write(int b) throws IOException {
        if (count >= buf.length) {
            flushBuffer(); // 缓冲区满了，刷到文件
        }
        buf[count++] = (byte) b;
    }
    
    private void flushBuffer() throws IOException {
        out.write(buf, 0, count); // 真正写入底层流
        count = 0;
    }
}
```

### 3.3 性能对比

```java
// 1. 普通字节流：单字节读写
FileInputStream fis = new FileInputStream("large.txt");
FileOutputStream fos = new FileOutputStream("copy.txt");
int b;
while ((b = fis.read()) != -1) {  // 每次一个字节，上亿次系统调用
    fos.write(b);
}
// 耗时：约 200 秒（2GB 文件）

// 2. 普通字节流 + 自定义 byte[] 缓冲区
FileInputStream fis = new FileInputStream("large.txt");
FileOutputStream fos = new FileOutputStream("copy.txt");
byte[] buf = new byte[8192];
int len;
while ((len = fis.read(buf)) != -1) {  // 每次 8KB
    fos.write(buf, 0, len);
}
// 耗时：约 2 秒（快了 100 倍）

// 3. 缓冲流
BufferedInputStream bis = new BufferedInputStream(new FileInputStream("large.txt"));
BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("copy.txt"));
int b;
while ((b = bis.read()) != -1) {
    bos.write(b);
}
// 耗时：约 3 秒（比方案 2 略慢，因为还有内部函数调用开销）
```

> **重要结论**：缓冲流 + 单字节读写 ≈ 节点流 + 字节数组读写（性能接近，底层都是数组操作）

### 3.4 flush() 机制

```java
public void flush() throws IOException {
    flushBuffer();  // 将缓冲区数据写入文件
    out.flush();    // 调用底层流的 flush
}
```

什么时候触发 flush：
1. 缓冲区满了 → 自动 flush
2. 手动调用 flush()
3. close() 时 → 调用链：close() → flush() → 关闭底层流

## 4. 练习：文件复制

### 方式一：缓冲流 + 单字节（慢）

```java
try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("src.txt"));
     BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("dest.txt"))) {
    int b;
    while ((b = bis.read()) != -1) {
        bos.write(b);
    }
}
```

### 方式二：缓冲流 + 字节数组（最快）

```java
try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("src.txt"));
     BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("dest.txt"))) {
    byte[] buf = new byte[8192];
    int len;
    while ((len = bis.read(buf)) != -1) {
        bos.write(buf, 0, len);
    }
}
```

> **终极方案**：缓冲流包装 + 自定义 byte[] 数组读写 = 最高性能

## 总结

1. **缓冲流**是包装流/处理流，包装节点流提供缓冲区功能
2. **内部 byte[] 缓冲区**（默认 8KB）减少系统调用次数
3. **四大金刚**：BufferedInputStream / BufferedOutputStream / BufferedReader / BufferedWriter
4. **性能对比**：缓冲流 + 单字节 ≈ 节点流 + 字节数组 >> 节点流 + 单字节
5. 写完数据**必须 flush 或 close**，否则缓冲区数据丢失
