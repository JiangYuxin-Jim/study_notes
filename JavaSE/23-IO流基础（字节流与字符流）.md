## 一、IO 流概述

### 1.1 IO 是什么

IO（Input/Output）就是输入输出。程序通过 IO 流与外部设备（文件、网络、键盘等）进行数据交互。

### 1.2 IO 流的分类

**按流向分：**

| 流向 | 说明 |
|------|------|
| **输入流** | 从外部设备**读入**程序（数据从外到内） |
| **输出流** | 从程序**写出**到外部设备（数据从内到外） |

**按类型分：**

| 类型 | 说明 | 核心抽象类 |
|------|------|-----------|
| **字节流** | 以字节为单位（1 字节 = 8 bit），可处理任何文件 | `InputStream` / `OutputStream` |
| **字符流** | 以字符为单位，专门处理纯文本文件 | `Reader` / `Writer` |

### 1.3 四大抽象基类

```
字节输入流   InputStream    (read)
字节输出流   OutputStream   (write)
字符输入流   Reader         (read)
字符输出流   Writer         (write)
```

> 四个基类都是**抽象类**，不能直接 new。它们定义了流的通用方法，具体实现由子类完成。

### 1.4 IO 流的三大原则

1. **用完必须关流** — 调用 `close()`，释放系统资源
2. **字符流只能操作纯文本文件** — 图片、视频、压缩包等只能用字节流
3. **继承自四大基类的类名后缀**：`XxxInputStream / XxxOutputStream / XxxReader / XxxWriter`

## 二、字节流

### 2.1 FileInputStream — 文件字节输入流

从文件中读取数据（字节）。

**构造方法：**

```java
FileInputStream fis = new FileInputStream("D:\\a.txt");
// 如果文件不存在，抛出 FileNotFoundException
```

**读取方式一：`read()` — 一次读一个字节**

```java
FileInputStream fis = new FileInputStream("D:\\a.txt");
int b;
while ((b = fis.read()) != -1) {
    System.out.print((char) b);
}
fis.close();
// 输入文件中是 "abc"，输出：a b c
// read() 返回的是字节的 int 值（0~255），读到最后返回 -1
```

**读取方式二：`read(byte[] buffer)` — 一次读一个字节数组**

```java
FileInputStream fis = new FileInputStream("D:\\a.txt");
byte[] buffer = new byte[1024];  // 1KB 缓冲区
int len;                         // 本次实际读取的字节数
while ((len = fis.read(buffer)) != -1) {
    // 将字节数组从 0 到 len 位置转换为字符串
    System.out.print(new String(buffer, 0, len));
}
fis.close();
// read(byte[]) 返回实际读取的字节数，读到末尾返回 -1
```

**两种读取方式的性能对比：**

| 方式 | 速度 | 原因 |
|------|------|------|
| `read()` 单字节 | 极慢 | 每次只读 1 个字节，系统调用次数非常多 |
| `read(byte[])` 数组 | 快很多 | 一次读一批字节到内存，减少系统调用 |

> `read()` 每次读一个字节就调用一次底层操作系统 API，效率极低。`read(byte[])` 一次读 n 个字节，系统调用次数减少为原来的 1/n，性能大幅提升。

### 2.2 FileOutputStream — 文件字节输出流

向文件中写入数据。

**构造方法：**

```java
// 默认覆盖模式（会清空原文件再写）
FileOutputStream fos = new FileOutputStream("D:\\a.txt");

// 追加模式（在文件末尾追加，不清空原内容）
FileOutputStream fos = new FileOutputStream("D:\\a.txt", true);
```

**写入方式：**

```java
FileOutputStream fos = new FileOutputStream("D:\\a.txt");

// 写入一个字节
fos.write(97);  // 写入了 ASCII 97，即字符 'a'

// 写入字节数组
byte[] bytes = "hello".getBytes();
fos.write(bytes);

// 写入字节数组的一部分
fos.write(bytes, 1, 3);  // 从 index 1 开始，写 3 个字节 → "ell"

fos.close();
```

### 2.3 文件拷贝案例

**方式一：一次一个字节（超慢）**

```java
public static void copy1(File src, File dest) throws IOException {
    FileInputStream fis = new FileInputStream(src);
    FileOutputStream fos = new FileOutputStream(dest);

    int b;
    while ((b = fis.read()) != -1) {
        fos.write(b);
    }

    fis.close();
    fos.close();
}
// 只适合超级小文件，大文件会慢到怀疑人生
```

**方式二：一次一个字节数组（推荐）**

```java
public static void copy2(File src, File dest) throws IOException {
    FileInputStream fis = new FileInputStream(src);
    FileOutputStream fos = new FileOutputStream(dest);

    byte[] buffer = new byte[8192];  // 8KB 缓冲区
    int len;
    while ((len = fis.read(buffer)) != -1) {
        fos.write(buffer, 0, len);   // 只写实际读取的长度，避免写入无效数据
    }

    fis.close();
    fos.close();
}
```

**方式三：try-catch-finally 释放资源**

```java
public static void copy3(File src, File dest) {
    FileInputStream fis = null;
    FileOutputStream fos = null;
    try {
        fis = new FileInputStream(src);
        fos = new FileOutputStream(dest);
        byte[] buffer = new byte[8192];
        int len;
        while ((len = fis.read(buffer)) != -1) {
            fos.write(buffer, 0, len);
        }
    } catch (IOException e) {
        e.printStackTrace();
    } finally {
        // 关流时分别 try-catch，避免其中一个抛出异常影响另一个
        try {
            if (fos != null) fos.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
        try {
            if (fis != null) fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## 三、字符流

### 3.1 为什么要有字符流

**字节流读汉字可能乱码：**

```java
// 文件 a.txt 保存了 "你好世界"，UTF-8 编码，一个汉字 3 个字节
FileInputStream fis = new FileInputStream("D:\\a.txt");
int b;
while ((b = fis.read()) != -1) {
    System.out.print((char) b);  // 按字节转字符，把 3 个字节拆成 3 个 char
}
// 输出乱码：ä½ å¥½ä¸
–ç
// 因为一个汉字 3 字节，read() 一次只读 1 字节，把一个 UTF-8 汉字拆了
```

**字节数组读汉字也可能乱码：**

```java
byte[] buffer = new byte[4];  // 4 字节，不是 3 的倍数
// 读取 "你好世界"（12 字节），三次读取：
// 第1次：4 字节 → "你"的 3 字节 + "好"的 1 字节 → 乱码
// 第2次：4 字节 → "好"的 2 字节 + "世"的 2 字节 → 乱码
// ...
```

**字符流按字符读取，一个字符一个字符完整读取，不会拆散汉字，解决乱码问题。**

> **字符流 = 字节流 + 编码表**

字符流底层还是用字节读，但多了编码和解码的步骤，确保每次都读到完整的字符。

### 3.2 FileReader — 文件字符输入流

```java
FileReader fr = new FileReader("D:\\a.txt");

// 方式一：read() — 一次读一个字符
int ch;
while ((ch = fr.read()) != -1) {
    System.out.print((char) ch);
}
// 输出：你好世界（不乱码了！）

// 方式二：read(char[]) — 一次读一个字符数组（推荐）
char[] buffer = new char[1024];
int len;
while ((len = fr.read(buffer)) != -1) {
    System.out.print(new String(buffer, 0, len));
}

fr.close();
```

### 3.3 FileWriter — 文件字符输出流

```java
// 默认覆盖模式
FileWriter fw = new FileWriter("D:\\a.txt");

// 追加模式
FileWriter fw = new FileWriter("D:\\a.txt", true);
```

**写入方式：**

```java
FileWriter fw = new FileWriter("D:\\a.txt");

// 写入字符串
fw.write("你好世界");

// 写入字符数组
char[] chars = {'你', '好', '中', '国'};
fw.write(chars);

// 写入单个字符
fw.write('A');

// 写入字符串的一部分
fw.write("你好世界", 1, 2);  // 从 index 1（"好"）开始，写 2 个字符 → "好世"

fw.close();
```

> **⚠️ 注意：** FileWriter 写入的数据会先进入**内存缓冲区**（默认 8192 字符），满了或调用 `flush()` 或 `close()` 时才真正写入文件。如果不调 close()，数据可能没写到文件。

### 3.4 字符流拷贝纯文本文件

```java
public static void copyTextFile(File src, File dest) throws IOException {
    FileReader fr = new FileReader(src);
    FileWriter fw = new FileWriter(dest);

    char[] buffer = new char[8192];
    int len;
    while ((len = fr.read(buffer)) != -1) {
        fw.write(buffer, 0, len);
    }

    fr.close();
    fw.close();
}
```

## 四、编码与解码

### 4.1 编码：String → byte[]

```java
String str = "你好世界";

// 默认编码（项目编码，一般是 UTF-8）
byte[] bytes1 = str.getBytes();
System.out.println(bytes1.length);
// UTF-8 下：一个汉字 3 字节，共 12 字节

// 指定编码
byte[] bytes2 = str.getBytes("UTF-8");     // 12 字节
byte[] bytes3 = str.getBytes("GBK");       // 8 字节（GBK 一个汉字 2 字节）
byte[] bytes4 = str.getBytes("ISO-8859-1");// 4 字节（不支持中文，会用 ? 代替）
```

### 4.2 解码：byte[] → String

```java
byte[] bytes = "你好世界".getBytes("UTF-8");

// 用正确的编码解码
String s1 = new String(bytes, "UTF-8");      // "你好世界" ✅

// 用错误的编码解码
String s2 = new String(bytes, "GBK");        // 乱码 ❌
String s3 = new String(bytes, "ISO-8859-1"); // 乱码 ❌
```

### 4.3 乱码的常见原因与解决

**场景：** 一个 GBK 编码的文件，程序用 UTF-8 读取，导致乱码。

```java
// ❌ 直接使用 FileReader（使用项目默认编码）
FileReader fr = new FileReader("D:\\gbk.txt");  // 如果项目是 UTF-8，读 GBK 文件会乱码
```

**解决思路：** 用转换流（`InputStreamReader`）指定与文件一致的编码读取（详见下篇笔记）。

### 4.4 常见编码表

| 编码 | 说明 | 英文字符 | 中文字符 |
|------|------|---------|---------|
| **ASCII** | 7 bit 编码，128 个字符 | 1 字节 | 不支持 |
| **ISO-8859-1** | 扩展 ASCII | 1 字节 | 不支持（全变成 ?） |
| **GBK** | 中文编码标准 | 1 字节 | **2 字节** |
| **UTF-8** | Unicode 的实现，通用编码 | 1 字节 | **3 字节** |

**UTF-8 编码规则（了解）：**
- 单字节字符（ASCII）：`0xxxxxxx`
- 双字节字符（拉丁、希腊等）：`110xxxxx 10xxxxxx`
- 三字节字符（中文、日文等）：`1110xxxx 10xxxxxx 10xxxxxx`

## 五、要点总结

| 分类 | 核心类 | 说明 |
|------|--------|------|
| 字节输入流 | FileInputStream | 读字节，适合任何文件 |
| 字节输出流 | FileOutputStream | 写字节，支持覆盖/追加模式 |
| 字符输入流 | FileReader | 读字符，适合纯文本文件 |
| 字符输出流 | FileWriter | 写字符，有缓冲区需 flush/close |
| 编码 | String.getBytes(charset) | 字符串 → 字节数组 |
| 解码 | new String(bytes, charset) | 字节数组 → 字符串 |
| 缓冲区 | byte[] / char[] | 数组缓冲区提升性能 |
