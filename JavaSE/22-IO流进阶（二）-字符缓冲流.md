# IO流进阶（二）- 字符缓冲流

## 1. 字符缓冲流概述

### 1.1 为什么需要字符缓冲流？

- 字符流（FileReader/FileWriter）继承了字节缓冲流的缓冲区思想
- 提供了 **按行读写** 的特殊方法，是字符缓冲区最大的亮点

### 1.2 构造方式

```java
// 字符缓冲输入流
FileReader fr = new FileReader("a.txt");
BufferedReader br = new BufferedReader(fr);

// 字符缓冲输出流
FileWriter fw = new FileWriter("a.txt");
BufferedWriter bw = new BufferedWriter(fw);
```

## 2. BufferedReader

### 2.1 构造方法

```java
BufferedReader(Reader in)          // 默认 8192 字符缓冲区
BufferedReader(Reader in, int sz)  // 自定义缓冲区大小
```

### 2.2 特有方法：readLine()

这是 BufferedReader **最强大的方法**，普通字符流没有：

```java
public String readLine() throws IOException
```

- 读取一行文本（遇到换行符 \n、\r 或 \r\n 结束）
- 返回的**字符串不包含换行符**
- 读到末尾返回 **null**

```java
try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);  // 输出一行
    }
}
```

### 2.3 原理

内部维护一个 **char[] cb** 缓冲区（默认 8192 个字符）

```java
// 简化原理
public class BufferedReader extends Reader {
    private char cb[];    // 内部字符缓冲区
    private int nChars;   // 缓冲区有效字符数
    private int nextChar; // 下一个读取位置
    
    public String readLine() throws IOException {
        StringBuilder sb = new StringBuilder();
        while (true) {
            if (nextChar >= nChars) {
                fill(); // 从底层流读取数据填充缓冲区
            }
            char c = cb[nextChar++];
            if (c == '\n') break;
            if (c == '\r') {
                // 检查是否后面跟 \n → \r\n 一起跳过
                if (nextChar < nChars && cb[nextChar] == '\n') {
                    nextChar++;
                }
                break;
            }
            sb.append(c);
        }
        return sb.length() > 0 ? sb.toString() : null;
    }
}
```

## 3. BufferedWriter

### 3.1 构造方法

```java
BufferedWriter(Writer out)          // 默认 8192 字符缓冲区
BufferedWriter(Writer out, int sz)  // 自定义缓冲区大小
```

### 3.2 特有方法：newLine()

```java
public void newLine() throws IOException
```

- 写入一个跨平台换行符（Windows → `\r\n`，Linux → `\n`，Mac → `\r`）
- 比手动写 `bw.write("\n")` 更**可移植**

```java
try (BufferedWriter bw = new BufferedWriter(new FileWriter("b.txt"))) {
    bw.write("第一行");
    bw.newLine();  // 换行
    bw.write("第二行");
    bw.newLine();
}
```

## 4. 综合练习

### 4.1 文件复制（字符缓冲流）

```java
try (BufferedReader br = new BufferedReader(new FileReader("src.txt"));
     BufferedWriter bw = new BufferedWriter(new FileWriter("dest.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        bw.write(line);
        bw.newLine();  // readLine() 去掉了换行符，要自己加回来
    }
}
```

### 4.2 排序练习：恢复被打乱的文件

**需求**：文件内容被打乱成乱序的编号行，恢复正确顺序

```
// 乱序文件内容
3.等待
2.加载中
1.你好

// 目标恢复
1.你好
2.加载中
3.等待
```

```java
public class SortFileDemo {
    public static void main(String[] args) throws IOException {
        // 1. 读取所有行
        List<String> lines = new ArrayList<>();
        try (BufferedReader br = new BufferedReader(new FileReader("乱序.txt"))) {
            String line;
            while ((line = br.readLine()) != null) {
                lines.add(line);
            }
        }
        
        // 2. 按行号排序
        lines.sort((a, b) -> {
            int numA = Integer.parseInt(a.substring(0, a.indexOf(".")));
            int numB = Integer.parseInt(b.substring(0, b.indexOf(".")));
            return Integer.compare(numA, numB);
        });
        
        // 3. 写入新文件
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("正确顺序.txt"))) {
            for (String line : lines) {
                bw.write(line);
                bw.newLine();
            }
        }
    }
}
```

## 5. IO 流体系总结（截至字符缓冲流）

```
字节流
├── 节点流
│   ├── FileInputStream（字节输入流）
│   └── FileOutputStream（字节输出流）
├── 缓冲流
│   ├── BufferedInputStream
│   └── BufferedOutputStream

字符流
├── 节点流
│   ├── FileReader（字符输入流）
│   └── FileWriter（字符输出流）
├── 缓冲流
│   ├── BufferedReader（特有 readLine()）
│   └── BufferedWriter（特有 newLine()）
├── 转换流（InputStreamReader / OutputStreamWriter）
├── 序列化流（ObjectInputStream / ObjectOutputStream）
├── 打印流（PrintStream / PrintWriter）
├── 压缩流（ZipInputStream / ZipOutputStream）
└── Commons-IO 工具包
```

## 总结

1. **BufferedReader**：特有 `readLine()` 按行读取，返回不包含换行符的字符串
2. **BufferedWriter**：特有 `newLine()` 跨平台换行
3. **字符缓冲流 + 按行读写**是日常文本处理最常用的方式
4. readLine() 去掉了换行符，写入时需要手动 newLine() 恢复
