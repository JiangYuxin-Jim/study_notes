# IO流进阶（三）- 转换流与序列化流

## 1. 转换流

### 1.1 为什么需要转换流？

**问题**：FileReader/FileWriter 使用 IDE 或系统默认编码（UTF-8），但很多旧文件是 GBK 编码

```java
FileReader fr = new FileReader("GBK编码的文件.txt");  
// 默认用 UTF-8 解码 → 乱码！
```

**解决方案**：转换流可以**指定编码**

### 1.2 InputStreamReader

**字节输入流 → 字符输入流**的桥梁，可以指定解码字符集

```java
public class InputStreamReader extends Reader {
    // 将字节输入流转换为字符输入流，指定编码
    public InputStreamReader(InputStream in)                  // 默认编码
    public InputStreamReader(InputStream in, String charset)  // 指定编码
}
```

```java
// 读取 GBK 文件
InputStreamReader isr = new InputStreamReader(
    new FileInputStream("gbk.txt"), "GBK"
);
int ch;
while ((ch = isr.read()) != -1) {
    System.out.print((char) ch);
}
isr.close();

// 套上缓冲流提升性能
BufferedReader br = new BufferedReader(
    new InputStreamReader(new FileInputStream("gbk.txt"), "GBK")
);
String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}
br.close();
```

### 1.3 OutputStreamWriter

**字符输出流 → 字节输出流**的桥梁，可以指定编码

```java
public class OutputStreamWriter extends Writer {
    public OutputStreamWriter(OutputStream out)                  // 默认编码
    public OutputStreamWriter(OutputStream out, String charset)  // 指定编码
}
```

```java
OutputStreamWriter osw = new OutputStreamWriter(
    new FileOutputStream("gbk_out.txt"), "GBK"
);
osw.write("你好世界");
osw.close();
```

### 1.4 综合应用：编码转换

```java
// GBK → UTF-8 文件转换
public class CharsetConverter {
    public static void main(String[] args) throws IOException {
        // 以 GBK 读取
        BufferedReader br = new BufferedReader(
            new InputStreamReader(new FileInputStream("gbk.txt"), "GBK")
        );
        // 以 UTF-8 写出
        BufferedWriter bw = new BufferedWriter(
            new OutputStreamWriter(new FileOutputStream("utf8.txt"), "UTF-8")
        );
        
        String line;
        while ((line = br.readLine()) != null) {
            bw.write(line);
            bw.newLine();
        }
        
        br.close();
        bw.close();
    }
}
```

**使用场景**：旧系统迁移、数据导入导出、跨平台文件处理

## 2. 对象操作流（序列化与反序列化）

### 2.1 什么是序列化？

- **序列化**：将 Java 对象转换为字节序列（byte[]），可保存到文件或网络传输
- **反序列化**：将字节序列恢复为 Java 对象

### 2.2 ObjectOutputStream（序列化）

#### 构造方法

```java
ObjectOutputStream(OutputStream out)
```

#### 特有方法：writeObject()

```java
public final void writeObject(Object obj) throws IOException
```

#### 使用步骤

1. 创建 FileOutputStream
2. 包装成 ObjectOutputStream
3. 调用 writeObject() 写入对象
4. 关闭流

```java
// 1. 定义可序列化的类
public class Student implements Serializable {
    private String name;
    private int age;
    
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    @Override
    public String toString() {
        return "Student{name='" + name + "', age=" + age + "}";
    }
}

// 2. 序列化
Student s = new Student("张三", 23);
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("student.txt"))) {
    oos.writeObject(s);
}
```

### 2.3 ObjectInputStream（反序列化）

#### 构造方法

```java
ObjectInputStream(InputStream in)
```

#### 特有方法：readObject()

```java
public final Object readObject() throws IOException, ClassNotFoundException
```

```java
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("student.txt"))) {
    Student s = (Student) ois.readObject();  // 需要向下转型
    System.out.println(s);
}
```

### 2.4 Serializable 接口

```java
public interface Serializable {
    // 没有任何方法！仅仅是标记接口
}
```

**序列化条件**：
1. 类必须实现 `Serializable` 接口
2. 类的所有属性也必须是可序列化的（**基本类型**本身可序列化）
3. static 和 transient 修饰的成员变量不会被序列化

**不实现 Serializable 的后果**：
```
java.io.NotSerializableException: com.example.Student
```

### 2.5 serialVersionUID

#### 问题：序列化版本冲突

```java
// 第 1 次：序列化
ObjectOutputStream oos = new ObjectOutputStream(...);
oos.writeObject(student);  // 序列化时，JVM 根据类结构生成 UID
oos.close();

// 修改了 Student 类（加了新字段）
// public class Student implements Serializable {
//     private String name;
//     private int age;
//     private String gender;  // 新增
// }

// 第 2 次：反序列化（用旧的序列化文件）
ObjectInputStream ois = new ObjectInputStream(...);
Student s = (Student) ois.readObject();  // InvalidClassException!
// 因为修改后类结构和原来不同，UID 变了
```

#### 解决方案：显式声明 serialVersionUID

```java
public class Student implements Serializable {
    private static final long serialVersionUID = 1L;  // 固定版本号
    
    private String name;
    private int age;
    // 即使后面加字段，反序列化时使用固定 UID，不报错
    // private String gender;  // 新增后反序列化也能成功
}
```

### 2.6 transient 关键字

```java
public class Student implements Serializable {
    private static final long serialVersionUID = 1L;
    
    private String name;
    private transient int age;  // 年龄不参与序列化
    private transient String password;  // 密码敏感，不序列化
}
```

`transient` 修饰的字段：
- 序列化时 **跳过**，不写入文件
- 反序列化时恢复为 **默认值**（int → 0，String → null）

**用途**：密码、敏感信息、无需保存的临时数据

### 2.7 序列化多个对象

#### 方式一：集合（推荐）

```java
// 写入
List<Student> list = new ArrayList<>();
list.add(new Student("张三", 23));
list.add(new Student("李四", 24));

try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("students.txt"))) {
    oos.writeObject(list);  // 序列化整个集合
}

// 读取
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("students.txt"))) {
    List<Student> list = (List<Student>) ois.readObject();
    for (Student s : list) {
        System.out.println(s);
    }
}
```

#### 方式二：多次写入（需要知道写了几个）

```java
// 写入
oos.writeObject(s1);
oos.writeObject(s2);
oos.writeObject(s3);

// 读取（必须知道顺序和数量）
Student s1 = (Student) ois.readObject();
Student s2 = (Student) ois.readObject();
Student s3 = (Student) ois.readObject();
```

## 3. 练习：点名器

```java
public class RandomRollCall {
    public static void main(String[] args) throws Exception {
        // 假设 students.txt 是序列化文件
        
        // 1. 反序列化读取学生列表
        List<Student> list;
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("students.txt"))) {
            list = (List<Student>) ois.readObject();
        }
        
        // 2. 随机点名
        Random r = new Random();
        int index = r.nextInt(list.size());
        System.out.println("被点到的是：" + list.get(index));
    }
}
```

## 总结

### 转换流
| 类 | 作用 | 使用场景 |
|----|------|---------|
| InputStreamReader | 字节流 → 字符流，可指定解码编码 | 读取 GBK 等非 UTF-8 文件 |
| OutputStreamWriter | 输出字符流 → 字节流，可指定编码 | 以指定编码写入文件 |

### 序列化流
| 类 | 作用 | 关键方法 |
|----|------|---------|
| ObjectOutputStream | 序列化对象到文件 | writeObject(Object) |
| ObjectInputStream | 从文件反序列化对象 | readObject() |

### 关键点
1. 类必须实现 **Serializable** 接口
2. 显式声明 **serialVersionUID** 防止版本冲突
3. **transient** 修饰的字段跳过序列化
4. 序列化多个对象推荐用**集合**包装
