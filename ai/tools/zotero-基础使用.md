# Zotero 文献管理 · 基础使用

> 学习日期：2026-08-29
> 工具类型：文献管理软件（引用管理 Reference Manager）
> 定位：研究/论文写作闭环的重要一环，与 AI 主线（RAG、知识库）天然互补——文献是知识库的重要数据源。

---

## 一、Zotero 是什么

- **开源免费的文献管理工具**，用于收集、组织、引用、共享研究资料。
- 社区/学校常用（相比 EndNote 免费开放，相比 Mendeley 开源）。
- **核心定位**：把"散落的 PDF/网页/书籍"统一管理成结构化文献库，随时生成参考文献。

### 为什么对 AI 学习有用
- 你的 RAG / 知识库 / 论文写作，**文献就是高质量数据源**。
- Zotero 能把文献转成结构化数据 + 统一格式 PDF，方便后续喂给 RAG 或智能体做问答。

---

## 二、核心概念

| 概念 | 说明 |
|------|------|
| **Library（文献库）** | 主数据库，存所有条目；My Library 是默认库 |
| **Collection（分类集）** | 类似文件夹，用来给文献分组（可多级、一个条目可属于多个分类） |
| **Item Type（条目类型）** | 期刊文章 / 书籍 / 网页 / 学位论文 / 会议论文等，不同类型字段不同 |
| **Item（条目）** | 一条文献记录，含题名、作者、年份、期刊、DOI、PDF 附件等 |
| **Tag（标签）** | 轻量标记，跨分类检索用 |
| **Attachment（附件）** | 关联到条目的 PDF、网页快照等 |
| **Note（笔记）** | 挂在该条目的文字笔记（可高亮引用） |

## 三、基本使用方法

### 1. 新建 / 导入文献
- **直接创建**：点"新建条目"图标 → 选类型 → 手动填字段（题名、作者、年份…）。
- **网页抓取**：安装浏览器插件（Zotero Connector），在知网/PubMed/谷歌学术/网页上点一下，自动抓取元数据+PDF。
- **DOI 导入**：工具栏"由标识符添加"→ 输入 DOI / ISBN / PMID → 自动拉取完整信息。
- **批量导入**：支持 RIS / BibTeX / EndNote XML 等格式文件导入。

### 2. 分类与组织
- **分类集 Collection**：点右键"新建分类"，把条目拖入；支持子分类。
- **标签 Tag**：多选条目 → 右键"添加标签"，便于跨分类检索。
- **智能搜索**："保存搜索"可设条件自动归集（如"2024 年 + 含 PDF"）。

### 3. PDF 附件与阅读
- 把 PDF 拖进条目 → 变成附件，Zotero 内直接双击阅读。
- 可加**高亮、批注**（Zotero 6/7 内置 PDF 阅读器）。
- 高亮可一键转成笔记片段，方便回引原文。

### 4. 引用与参考文献（核心功能）
- 安装 **Word / WPS 插件**（Zotero 桌面端 → 工具 → 安装 Word 插件）。
- 光标定位 → 点"Add/Edit Citation"→ 搜索文献插入，**自动生成文中引注**（如 (作者, 年份)）。
- 点"Add/Edit Bibliography"→ **自动生成参考文献列表**。
- **引文格式**：点插件栏格式按钮切换（APA、MLA、GB/T 7714、芝加哥等），一键换格式。

### 5. 同步与备份
- Zotero 提供免费**官方云同步**（注册账号，默认 300MB 存储）。
- 大附件可配合 **WebDAV**（坚果云等）或 Zotero 存储方案扩展。
- 建议定期**导出备份**：文件 → 导出为 RIS/BibTeX，或整个库备份。

## 五、小结

- Zotero 用"**收集 → 组织 → 引用**"三步解决文献管理。
- 关键能力：**网页一键抓取、Collection+Tag 双维度组织、Word 插件自动引用/生成参考文献、可切换引文格式**。
- 进阶方向（后续可学）：Zotero 插件生态（翻译、GPT/AI 插件）、与 RAG/知识库打通、Zotero 7 新特性、样式定制 CSL。
