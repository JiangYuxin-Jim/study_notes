# 第二章 智能体发展史

> 学习日期：2026-10-18
> 课程：hello-agents / 第二章「智能体发展史」
> 核心主题：用一条时间线把智能体从"符号主义 → 专家系统 → 强化学习 → LLM 驱动"讲清楚，理解今天"LLM + 工具 + 循环"这套形态**为什么**会胜出，以及每一代范式留下的遗产（记忆、工具调用、规划、循环）分别对应我们学过的哪一章。

---

## 2.1 为什么先学历史

- 智能体不是 2022 年突然出现的新东西，而是**人工智能六十多年追求"自主行动"的延续**。
- 每一代范式都在回答同一个问题：**机器怎么在不确定环境里自己决定下一步做什么？**
- 历史给的是"设计词汇表"：ReAct、Reflection、Plan-and-Solve 这些现代范式，几乎都能在早期思路里找到祖先。

---

## 2.2 四代演进

### 第一代：符号主义与物理符号系统（1950s–1980s）

- 核心假设（Newell & Simon 的物理符号系统假说）：**智能 = 符号操作**，只要符号表示足够完备，推理就能产生智能。
- 代表：逻辑理论家（Logic Theorist）、通用问题求解器（GPS）、早期规划系统（STRIPS）。
- 形态：**感知 → 符号化表示 → 搜索/规划 → 动作**，规则由人写死。
- 致命问题：**符号接地难题**（符号与真实世界的意义脱节）+ **组合爆炸** + 无法处理模糊与感知类任务。

### 第二代：专家系统（1980s–1990s）

- 把人类专家知识写成 **if-then 规则库 + 推理机**，在垂直领域（医疗诊断、故障排查）一度商业化成功。
- 进步：**知识**被显式地当作一等公民（知识库 + 推理引擎分离）。
- 失败原因：**知识获取瓶颈**（规则要人一条条手写）、维护困难（规则互相冲突）、无法泛化、脆弱（边界外直接崩）。
- 遗产：**把"领域知识"外置** 这个想法，正是今天 RAG / 知识库的前身。

### 第三代：强化学习智能体（1990s–2010s）

- 范式转换：不再手写规则，而是让智能体**在环境中试错、用奖励信号学习策略**（MDP：状态-动作-奖励）。
- 里程碑：TD-Gammon、DQN 玩 Atari、AlphaGo / AlphaZero。
- 核心词汇：**策略（policy）、价值函数、探索与利用（exploration vs exploitation）、回报折扣**。
- 进步：真正**从经验中学习**，在封闭、规则明确的环境里超越人类。
- 局限：**样本效率极低**（要百万次试错）、**奖励设计困难**、**难以迁移**（换个环境重学）、开放世界没有明确奖励信号。

### 第四代：LLM 驱动的智能体（2022– 至今）

- 转折点：大模型带来了**通用推理 + 世界知识 + 自然语言接口**三合一，第一次不需要为每个任务重新训练。
- 形态定型：**智能体 = LLM（大脑）+ 工具（手脚）+ 循环（自主性）+ 记忆（连续性）**。
- 关键范式演进（都能在前三代找到影子）：
  - **ReAct**（2022）：Thought → Action → Observation 循环，把"推理"和"行动"交织 → 对应第一代的规划搜索 + 第三代的试错。
  - **Reflexion**：自我反思、把失败经验写进记忆再重试 → 对应第二代"把经验显式化"。
  - **Toolformer / Function Calling**：让模型学会调用外部工具 → 对应第一代"符号操作外部世界"。
  - **Plan-and-Solve / Tree of Thoughts**：先规划再执行、多路径搜索 → 直接继承第一代的规划与搜索。
  - **多智能体协作**：分工、辩论、评审 → 对应人类组织形态，也是第三代"多体强化学习"的社会化版本。
- 仍然没解决的：**幻觉、上下文有限、长期记忆、可靠性、成本**——这些正是后面各章（记忆与检索、上下文工程、通信协议）要解决的问题。

## 2.3 一条主线看四代

| 代 | 智能来源 | 知识从哪来 | 主要瓶颈 | 现代遗产 |
|----|---------|-----------|---------|---------|
| 符号主义 | 人写的规则 + 搜索 | 人工符号化 | 接地难题、组合爆炸 | 规划、搜索、符号操作 |
| 专家系统 | 领域知识库 + 推理机 | 专家手写 if-then | 知识获取瓶颈、脆弱 | 知识外置（→ RAG/知识库） |
| 强化学习 | 试错 + 奖励 | 与环境交互 | 样本效率、奖励设计、迁移 | 探索、反馈驱动、策略优化 |
| LLM 智能体 | 预训练世界知识 + 推理 | 海量语料 + 工具 + 检索 | 幻觉、上下文、可靠性、成本 | 通用性、自然语言接口 |

> 💡 一句话总结：**智能体的历史 = 从"人把知识写成规则"到"模型自己从数据里长知识"，再到"模型 + 外部知识与工具"的螺旋上升。**
