## 一、什么是智能体（Agent）

### 核心定义
智能体是任何能够通过**传感器（Sensors）**感知其环境（Environment），并**自主**地通过**执行器（Actuators）**采取**行动（Action）**以达成特定目标的实体。

**四大基本要素：**
| 要素 | 说明 | 例子 |
|------|------|------|
| 环境 Environment | 智能体所处的外部世界 | 道路交通、金融市场 |
| 感知 Sensors | 获取环境信息的方式 | 摄像头、麦克风、API 返回数据流 |
| 执行器 Actuators | 对环境施加影响的手段 | 机械臂、方向盘、执行代码、调用服务 |
| 自主性 Autonomy | 独立决策而非被动响应 | 基于感知和内部状态达成设计目标 |

> 一句话：**智能体 = 感知环境的输入 → 自主决策 → 通过行动改变环境，形成闭环。**

## 二、传统智能体的演进（4 种范式）

传统（非 LLM）智能体经历了一条从简单到复杂的演进路线：

### 1. 简单反射智能体（Simple Reflex Agent）
- 决策由工程师显式设计的**"条件-动作"规则**构成。
- 经典例子：自动恒温器（室温高于设定值 → 启动制冷）。
- 局限：依赖当前感知，**无记忆、无预测**，无法处理需理解上下文的复杂任务。

### 2. 基于模型的反射智能体（Model-Based Reflex Agent）
- 引入内部**世界模型（World Model）**，追踪环境无法直接感知的方面。
- 例子：隧道里的自动驾驶汽车，摄像头看不到前方车辆，但内部模型维持对车辆位置/速度的判断。
- 进步：拥有初级的"记忆"，决策基于更连贯的世界状态理解。

### 3. 基于目标的智能体（Goal-Based Agent）
- 主动、有预见性地选择能导向特定目标状态的行为，核心是**规划（Planning）**。
- 例子：GPS 导航（基于地图搜索最优路径，如 A* 算法）。
- 进步：从"被动反应"到"主动规划未来"。

### 4. 基于效用的智能体（Utility-Based Agent）
- 为每个可能世界状态赋予**效用值**，目标是**最大化期望效用**。
- 例子：导航时不仅到公司，还要时间最短、最省油、避开拥堵——**多目标权衡**。
- 进步：在冲突目标间理性取舍，接近人类决策。

### 5. 学习型智能体（Learning Agent）
- 不依赖预设，**通过与环境互动自主学习**，代表是**强化学习（RL）**。
- 结构：性能元件（前述各类智能体）+ 学习元件（观察行动结果修正策略）。
- 例子：AlphaGo Zero 自我对弈发现超越人类知识的新策略。

> 演进主线：**规则(恒温器) → 内部模型(汽车) → 规划(导航) → 效用权衡(决策) → 自主学习(AlphaGo)。**

## 三、大语言模型驱动的新范式（LLM Agent）

GPT 等大模型出现后，智能体的核心决策机制发生本质改变：

| 维度 | 传统智能体 | LLM 智能体 |
|------|-----------|-----------|
| 核心引擎 | 显式编程 + 人工知识构建 | 预训练获得的隐式世界模型 + 涌现能力 |
| 行为模式 | 确定、有边界 | 灵活、通用 |
| 输入 | 结构化数据 | **高层级、模糊、充满上下文的自然语言** |

**以"智能旅行助手"为例展示 LLM Agent 能力：**
- **规划与推理**：把"规划一次厦门之旅"分解为 `[确认偏好] → [查目的地] → [订行程草案] → [预订票务住宿]`
- **工具使用**：识别信息缺口，主动调用天气接口（"预报有雨" → 倾向于推荐室内活动）
- **动态修正**：把用户反馈（"这家酒店超预算"）作为新约束，重新搜索调整

> 核心转变：**从"开发专用自动化工具"转向"构建自主解决问题的系统"——不再是写代码，而是引导通用"大脑"去规划、行动和学习。**

## 四、智能体的类型（3 个分类维度）

### 维度 1：内部决策架构
即前述传统演进阶梯：反应式 → 模型式 → 基于目标 → 基于效用；学习能力是可叠加的元能力。

### 维度 2：时间与反应性（速度 vs 最优解的权衡）
| 类型 | 特点 | 优势 | 代价 | 例子 |
|------|------|------|------|------|
| **反应式** Reactive | 对刺激即刻响应，决策延迟极低 | 速度快、开销低 | 短视、易局部最优 | 安全气囊、高频交易 |
| **规划式** Deliberative | 行动前深思熟虑，利用世界模型探索可能性 | 有远见、能处理复杂任务 | 时间/计算成本高、可能错过时机 | 棋手、出差规划 |
| **混合式** Hybrid | 反应 + 规划结合 | 兼顾即时响应与长期目标 | — | 智能旅行助手 |

**LLM 智能体本质是混合式**：在"思考-行动-观察"循环中融合两者——规划（Reasoning，审议过程）+ 反应（Acting & Observing，交互反馈过程）。

### 维度 3：知识表示（半个世纪的 AI 文化之争）
| 范式 | 核心 | 类比 | 优势 | 劣势 |
|------|------|------|------|------|
| **符号主义** Symbolic | 智能源于对符号的逻辑操作（规则/知识图谱） | 图书管理员 | 透明、可解释、可追溯 | 脆弱、"知识获取瓶颈" |
| **亚符号主义** Sub-symbolic | 知识内隐于神经网络，从数据学统计模式 | 牙牙学语的孩童 | 模式识别强、鲁棒、能处理非结构化数据 | **黑箱**、不可解释、易幻觉 |
| **神经符号主义** Neuro-Symbolic | 融合两者：既能学习又能逻辑推理 | 卡尼曼双系统理论 | 兼具直觉与理性 | — |

> 💡 **双系统理论**：系统1（快速直觉/并行）= 亚符号主义的模式识别；系统2（缓慢审慎/逻辑）= 符号主义推理。人类智能是两者协同。**LLM 智能体是神经符号主义的实践**——内核是神经网络（感知/语言），但输出结构化中间步骤（思想/计划/API调用，即符号）。

## 五、任务环境：PEAS 模型

用 **PEAS** 精确描述智能体所处的任务环境：

| 维度 | 全称 | 含义 | 旅行助手例子 |
|------|------|------|------|
| **P** | Performance 性能度量 | 如何评价成功 | 行程满意度、预算内 |
| **E** | Environment 环境 | 所处环境 | 航班/酒店/天气数据 |
| **A** | Actuators 执行器 | 如何行动 | 调用订票 API、输出行程 |
| **S** | Sensors 传感器 | 如何感知 | 查询航班/天气 API 返回 |

### LLM 数字环境的复杂特性（影响设计）
1. **部分可观察**：无法一次获取全部信息 → 需记忆（记住已查航线）+ 探索（尝试不同日期）
2. **随机性**：两次查询结果可能不同 → 需处理不确定性、监控变化、及时决策
3. **多智能体**：环境中存在其他行动者（其他用户、自动脚本、动态调价）→ 需快速响应、灵活策略
4. **序贯 + 动态**：当前动作影响未来；环境自身也在变 → 循环须快速适配

## 六、运行机制：智能体循环（Agent Loop）

智能体通过**"感知-思考-行动-观察"**持续循环与环境交互：

1. **感知（Perception）**：通过传感器接收输入，即**观察（Observation）**（用户指令或上一步反馈）。
2. **思考（Thought）**：核心决策阶段（LLM 内部推理），细分为：
   - **规划（Planning）**：更新理解，制定/调整行动计划，分解子任务
   - **工具选择（Tool Selection）**：从工具库选最合适的工具及参数
3. **行动（Action）**：通过执行器执行（调用工具、代码解释器、搜索 API），改变环境状态。
4. **状态变化 → 新观察**：环境产生新反馈，进入下一轮循环，直到达成目标。

> 智能体 = 不断重复此循环，从初始状态逐步推进到目标状态。

---

## 七、交互协议：Thought / Action / Observation

为了让 LLM 驱动循环，需要**交互协议**规范信息交换。LLM 输出不是单一自然语言回复，而是**结构化文本**，含两部分：

- **Thought（思考）**：内部决策快照，自然语言阐述如何分析情境、回顾观察、自我反思、分解问题、规划下一步。
- **Action（行动）**：决策后对环境的操作，通常以**函数调用**形式。

```
Thought: 用户想知道北京的天气。我需要调用天气查询工具。
Action: get_weather("北京")
```

执行后：
1. **解析器（Parser）** 捕捉 Action 指令，调用对应函数。
2. 环境返回原始结果（如 JSON）。
3. **感知系统**将原始输出处理封装为简洁自然语言（**Observation**）：
```
Observation: 北京当前天气为晴，气温25摄氏度，微风。
```
4. Observation 反馈给智能体，作为下一轮 `Thought`/`Action` 的输入。

> 通过 Thought-Action-Observation 循环，LLM 智能体把**内部语言推理**与**外部真实信息/工具操作**有效结合。

---

## 八、核心要点速记

- **智能体** = 感知(传感器) + 自主决策 + 行动(执行器)改变环境的闭环实体。
- **传统演进**：简单反射 → 模型式 → 目标式 → 效用式 → 学习式(RL)。
- **LLM Agent**：用预训练隐式世界模型处理模糊自然语言，能规划、用工具、动态修正。
- **混合式本质**：LLM Agent 在"思考-行动-观察"中融合**规划(审议)**与**反应(交互反馈)**。
- **知识表示三分**：符号(可解释/脆弱) · 亚符号(黑箱/模式识别) · 神经符号(融合，LLM Agent 即此) 。
- **PEAS** = 性能度量·环境·执行器·传感器，描述任务环境。
- **环境特性**：部分可观察、随机性、多智能体、序贯动态 → 决定 Agent 需记忆/探索/权衡。
- **Agent Loop**：感知 → 思考(规划+选工具) → 行动 → 观察，循环推进目标。
- **交互协议**：Thought(思考) + Action(函数调用)，Parser 执行，环境返回 Observation 入下一轮。
