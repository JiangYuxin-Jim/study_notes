## 8.1 为什么 Agent 需要"记忆系统"

LLM 本身是无状态的：每次请求都是一次全新的前向计算，**模型不记得上一次调用**。Agent 的"记忆"完全是工程层搭出来的，靠两条路：

1. **把历史塞回上下文**（context window 内）—— 对话消息、工具结果，随轮次增长不断膨胀；
2. **把历史写到上下文外**（文件 / 数据库）—— 需要时再读回来。

核心矛盾：**上下文窗口有限且昂贵**。因此记忆系统的本质不是"存多少"，而是"**在正确的时间，把正确的信息放回上下文**"。

> 💡 一句话定义：Agent 记忆 = 一套"外部存储 + 按需召回 + 写入规则"的机制，用来跨越单次上下文窗口的边界。

---

## 8.2 记忆的分层（工程视角）

对照认知科学与 Agent 落地，工程上常见的四层：

| 层级 | 载体 | 生命周期 | 典型内容 |
|------|------|---------|---------|
| **工作记忆** | 当前 context window | 单会话 | 本轮对话、最近工具返回值 |
| **会话记忆** | 会话记录 / transcript | 单次会话（可回放） | 完整对话历史、工具调用链 |
| **长期记忆** | 文件（如 CLAUDE.md、memory 目录） | 跨会话持久 | 用户偏好、项目约定、结论沉淀 |
| **外部知识** | 向量库 / 检索索引（RAG） | 持久 | 文档、代码库、领域知识 |

- 前两层是"**上下文内**"，后两层是"**上下文外**"，靠**读写动作**衔接；
- 与 hello-agents 的四分类（工作/情景/语义/感知）视角不同：那边按"信息性质"分，这边按"**存储位置与生命周期**"分——两者可相互映射（语义记忆 ≈ 长期记忆文件）。

## 8.3 Claude Code 的落地方式

### 8.3.1 CLAUDE.md —— 显式的长期记忆

- 项目根目录（及用户级 `~/.claude/CLAUDE.md`）的 Markdown 文件，**在每次会话启动时被读入上下文**；
- 用来放：项目结构说明、代码规范、常用命令、注意事项；
- 特点：**人写的、显式的、静态的**——是最便宜也最可控的一层记忆。
- 成本模型：属于"常驻订阅制"——每轮都占 token，所以要精简（与第六章 Subagent/Skill 的"按次加载"形成对比）。

### 8.3.2 自动记忆 / 会话内记忆

- 会话过程中 Agent 可以**主动把结论写进文件**（如 memory 笔记、TODO、进度文档），下次会话再读回；
- 本质是"**把上下文外化成文件**"，绕开上下文窗口上限；
- 写入时机很关键：通常在任务完成、得出重要结论、用户明确说"记住"时。

### 8.3.3 与上下文压缩的配合（第七章联动）

- 上下文快满时触发**压缩**（四级降级策略）：把旧内容摘要化/丢弃；
- 但压缩会丢失细节 → 因此**重要信息必须先落盘（写文件）再压缩**，压缩只保留摘要，需要细节时再读回；
- 公式化理解：**记忆系统 = 压缩的兜底**，没有外部存储，压缩就是不可逆的信息损失。

---

## 8.4 记忆系统的设计要点（通用原则）

1. **写什么**：只记"**下次还用得上**"的东西——偏好、约定、结论、决策理由；不记过程噪音。
2. **何时写**：任务收尾、重要结论、用户显式要求"记住"时写入，避免中途频繁写。
3. **何时读**：会话启动全量读（CLAUDE.md），任务中按需检索（RAG / 搜索），不要一股脑全塞。
4. **冲突处理**：新记忆与旧记忆矛盾时以"**新 + 显式确认**"为准，旧记录要标记失效而不是静默保留。
5. **成本意识**：常驻记忆（CLAUD.md）按轮计费 → 越短越好；按需记忆（检索）按次计费 → 越准越好。

> 💡 记忆系统的成熟标志：不是"记得多"，而是"**该记的记了、该忘的忘了、该想起来的时候想得起来**"。

---

## 8.5 本章总结

1. **LLM 无状态**，Agent 记忆全靠工程实现：上下文内（工作/会话）+ 上下文外（长期文件/外部知识）。
2. **CLAUDE.md 是显式长期记忆**，常驻上下文、成本按轮计，必须精简。
3. **自动记忆**本质是"把上下文外化成文件"，跨会话桥梁。
4. **记忆与压缩互补**：重要信息先落盘再压缩，才能既省 token 又不丢信息。
5. **设计心法**：该记的记、该忘的忘、该想起来时能想起来。

### 🔗 与 hello-agents 第八章对照
- hello-agents：按**信息性质**分四种记忆（工作/情景/语义/感知），偏"认知科学 + 抽象架构"；
- learn Claude Code：按**存储位置/生命周期**分（上下文内 vs 文件 vs 检索），偏"**工程落地与 token 成本**"；
- 两边都指向同一结论：**记忆 = 分层存储 + 按需召回 + 遗忘/压缩机制**。
